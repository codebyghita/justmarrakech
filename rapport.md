## 🗂️ 4. Gestion du Catalogue

### 4.1 — Gérer Activités

La liste complète de vos activités (Désert, Culture, etc.). Dans cette section, les activités sont organisées par **catégories**.

**Pour ajouter une activité :**
1. Cliquer sur le bouton **"+ Ajouter"** en haut à droite
2. Remplir les champs :
   - Titre de l'activité
   - Catégorie (Aventure, Culture, Bien-être, etc.)
   - Prix (en MAD, par personne)
   - Durée (ex: "3 heures")
   - Lieu (ex: "Médina de Marrakech")
   - Description courte et description longue
   - Ce qui est **Inclus** (un élément par ligne)
   - Ce qui **n'est pas inclus** (un élément par ligne)
   - Photos (upload ou URL)
   - ☑️ **"Mettre en avant sur l'accueil"** : cocher pour afficher dans la section "Activités Populaires"
3. Cliquer sur **"Enregistrer"**

**Pour modifier une activité :**
- Cliquer sur le crayon ✏️ de l'activité concernée → faire les modifications → **"Enregistrer"**

**Pour supprimer une activité :**
- Cliquer sur l'icône 🗑️ puis confirmer dans la fenêtre de confirmation

### 4.2 — Gérer Excursions

Contrairement aux activités, j'ai organisé les excursions de manière plus simple, sans sous-catégories, pour correspondre exactement à votre ancien site WordPress. Elles s'affichent toutes ensemble sur la page `/excursions`.

### 4.3 — Catégories

Gérez les catégories qui apparaissent sur la page Activités (ex: Aventure, Culture, Bien-être...).

- **Ajouter** : Nouvelle catégorie avec son nom, image et ordre d'affichage
- **Modifier** : Changer le nom ou l'image d'une catégorie existante
- **Supprimer** : Supprimer une catégorie (les activités liées resteront)

### 4.4 — Calendrier (Blocage de dates)

C'est ici que vous gérez vos disponibilités. Quand vous bloquez une date, les clients ne peuvent plus cliquer sur ce jour-là dans le calendrier de réservation du site.

- **Option Global** : Bloque tout le site (Activités et Excursions) sur une date précise.
- **Option Activité ou Excursion** : Vous permet de choisir un élément précis dans la liste. Les excursions sont maintenant clairement identifiées par le mot **(Excursion)** à côté de leur nom.

**Comment faire ?**
1. Choisissez la **Cible** (Global ou une activité/excursion).
2. Sélectionnez la **Date**.
3. Cliquez sur **Bloquer**.
4. Pour débloquer, cliquez sur la croix rouge dans la liste en bas de page.

### 4.5 — Avis Clients

Gérez les avis laissés par vos visiteurs.

- **Publier** un avis : cliquer sur l'icône 👁️ → il apparaît sur le site
- **Masquer** un avis : cliquer de nouveau sur l'icône 👁️
- **Supprimer** un avis : cliquer sur l'icône 🗑️

### 4.6 — Gérer le Blog

C'est ici que vous créez les articles pour votre section "Inspirations" (le blog).

1. **Accès** : Menu **"Gérer le Blog"** dans la barre latérale.
2. **Ajouter un article** : Bouton vert **"+ Nouvel Item"** en haut de la liste.
3. **Infos nécessaires** : Titre, Extrait (petit texte d'aperçu), Contenu complet (votre texte), Catégorie et Auteur.
4. **Statut** : Choisissez **"Publié"** pour qu'il soit visible, ou **"Brouillon"** pour le garder pour plus tard. Les adresses Internet (ex: `https://...`) que vous collez dans le texte deviennent **automatiquement cliquables**.
5. **Photos** : Ajoutez une belle photo de couverture via la zone "Galerie Photos" en bas du formulaire.

## 📱 6. Système de Réservation WhatsApp (Intelligent)

Chaque activité, excursion et séjour sur mesure possède un bouton **"Réserver sur WhatsApp"**. Voici comment ce système fonctionne :

1. Le visiteur choisit une activité et clique sur le bouton
2. WhatsApp s'ouvre **automatiquement** avec un message pré-rempli contenant :
   - Le nom de l'activité ou de la formule choisie
   - La date sélectionnée (si une date a été choisie)
   - Le nombre de personnes
3. Il n'y a plus qu'à répondre au client !

Le numéro WhatsApp est celui configuré dans les **Paramètres**. Il est nettoyé automatiquement (espaces, tirets, + supprimés) pour garantir que le lien fonctionne toujours, quel que soit le format saisi.

## 🎨 7. Design & Performances Techniques

### Performances
- **Temps de chargement :** Moins de 1 seconde (983ms au test de compilation)
- **Technologie frontend :** React + Vite (ultra-rapide)
- **Animations :** GSAP — j'utilise la technologie d'animation utilisée par Apple et les sites primés aux Awwwards pour garantir une fluidité maximale.
